# Changelog

## 0.1.4 - 2026-09-29

- Improve cTrader connector reliability and diagnostics across Local MCP, Open API, and FIX.
- Read and validate broker symbol volume metadata and fetch fresh account equity and free margin for cycle approval.
- Improve activity replay, startup and recovery visibility, and local market-data handling.
- Open the project for MIT-licensed code contributions and add contribution guidance.

This is an experimental Windows workbench. Evaluate it with a cTrader demo account and review the source before connecting any live account. It does not provide financial advice or promise trading performance.

See the commit history for detailed changes. Report defects through GitHub Issues and sensitive security concerns through the private reporting link in `SECURITY.md`.
