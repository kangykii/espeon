# Espeon design rules

- Use Lucide for every user-visible interface icon. Add icons through `src/icons.ts`; do not draw replacement SVG icons, use icon fonts, or use text glyphs as icons.
- The Espeon brand icon belongs on the desktop executable and shortcut only. Do not place it in the titlebar or app content.
- SVG paths used to display measured data, such as charts, are visualizations rather than interface icons.
